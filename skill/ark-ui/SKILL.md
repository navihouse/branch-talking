## 我做什么

- 给出配色、字阶、间距、网格与组件状态规范
- 产出可直接使用的 HTML / CSS（或 React 组件）结构与样式
- 保持高信息密度、克制的装饰、双语排版的严格对齐

## 何时用我

- 用户提到「工业科幻」「HUD」「仪表盘」「落地页」「设计系统」「编辑部排版」
- 需要把普通界面提升到有明确视觉语言的程度

## 我的准则

1. 先定视觉语言（色板 / 字阶 / 网格），再动具体组件
2. 装饰服务于信息层级，不做无意义纹理堆叠
3. 不复制任何受保护的 logo、角色或素材，只提炼风格特征
